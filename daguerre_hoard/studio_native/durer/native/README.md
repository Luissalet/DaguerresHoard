# Dürer engine

Detached Rust engine and desktop editor maintained in this repository. Historical source: VectorCraft v0.3.1, revision 7a39cb7b89505f7f6f19c83c66d46986d72d4aa9. Original copyright and license notices are retained in LICENSE-MIT, LICENSE-APACHE, NOTICE and ASSETS.md.

Build with `python scripts/build_engine.py`. The binaries, MCP resources and `.durer` document format belong to this Hoard. Legacy `.vectorcraft` and `.drawcraft` documents can be imported without changing their originals. No origin checkout, executable, service or future compatibility is required. The original asset-attribution file is retained as historical evidence; only fonts and open icons are incorporated. Product artwork comes from the existing Hoard icon.
