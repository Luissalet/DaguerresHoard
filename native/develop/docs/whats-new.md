# Daguerre Develop

The photo library, development pipeline, control catalogue, export formats and desktop editor are incorporated in this repository. They use Daguerre's engine and catalog identity. Original images remain read-only; editing workflows import copies in Daguerre data.

This source is a detached derivative of the historical version recorded in PROVENANCE.json. Licenses and asset attribution are retained. The origin application, executable, repository and future compatibility are not runtime dependencies.
