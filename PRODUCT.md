# Daguerre's Hoard

Daguerre is a local photo library. It indexes registered folders without modifying original images, keeps metadata, albums, duplicates and photo recipes, and offers search plus previews to people and agents. CLIP content search is optional; the color fallback is named honestly. Language-model functions use the configured shared backend. Native image editing does not use a text model.

The photo lightbox is the existing editing surface. It creates layered copies, develops copies, shows outputs, downloads editable projects and opens the full incorporated desktop editor. API, MCP and the browser call the same library implementation. Existing metadata, ratings, XMP sidecar behavior and photo-library functions remain available.

The layered and development engines and full desktop editors are detached source incorporated in this repository. They have own executables, crates, resources and formats, preserve original licenses and support historical imports. The complete catalog is discoverable; that is distinct from certifying every operation or RAW variant. Historical tool names remain aliases. Original images stay intact in the integrated copy workflows.

This change preserves the existing visual identity and layout. Its scope is the image-editor actions, names, availability and result controls in the lightbox. Native desktop editors preserve the complete incorporated interfaces, with Daguerre names and existing app artwork. Product source, build and functionality are verified separately from visual review.
